---
title: "New API release: Rule positioning on create, new policy controls and a pending-changes preview API"
date: 2026-07-22
slug: pending-changes-and-new-controls
summary: "You can now position rules and sections at create and update time, manage new Security and Customization controls, and preview pending changes before publishing a draft."
changes:
  - type: new
    text: "You can now set a rule or section's position when you <b>create or update</b> it, across all four policy types (Sign-In, Security, Access & Data, Customization). Place it at the top or bottom, or before or after an anchor, instead of making a separate positions call."
    endpoint: "Create a Security rule"
    to: /prisma-browser/api/create-security-rule
  - type: new
    text: "New Browser Security control <code>remoteDebugging</code>: allow or block remote debugging on Android and iOS devices to prevent data leaks and simplify troubleshooting."
  - type: new
    text: "New Browser Customization control <code>prismaBrowserDesktopExtender</code>: enable or disable Prisma Browser Local Extender (PABL). This capability is gated and being rolled out gradually, so it may not be available on your tenant yet."
  - type: new
    endpoint: "List pending changes"
    to: /prisma-browser/api/list-pending-changes
    text: "New endpoint to preview everything pending in your draft before you publish. Each item reports the entity, its type, what changed (<code>created</code>, <code>updated</code>, or <code>deleted</code>), and who changed it."
    example: |
      https GET api.sase.paloaltonetworks.com/seb-api/v1/configuration-management/draft/pending-changes \
        "Authorization: Bearer $TOKEN"
  - type: new
    text: "New <code>includeTotalCount</code> query parameter on list endpoints. The total count is already returned on the first page by default, so use this to skip it for speed or request it on later pages."
  - type: new
    text: "The <code>genAIPrompt</code> control now supports custom block-dialog text via <code>customDialogText</code>."
  - type: new
    text: "Access & Data logging can now include the text of prompts users submit to GenAI applications, via <code>shouldLogGenAiPrompt</code>. Available when <code>logLevel</code> is on or enhanced, and requires the <code>genAIPrompt</code> control."
  - type: new
    text: "Web-page watermarks expose new display options: <code>showCompanyLogo</code>, <code>showTextDetails</code> (email, timestamp), and <code>showQrCode</code>."
---

You can now position rules and sections when you create or update them, manage
new Security and Customization controls, and preview exactly what a draft will
promote before you publish.
